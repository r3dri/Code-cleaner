# code-cleaner
Code Cleaner — приватный веб-инструмент для удаления комментариев ИИ, пояснений и отладочных выводов из исходного кода. Поддерживает Python, JavaScript, Java, C++, Go, Rust, PHP и другие языки. Всё обрабатывается локально в браузере — без серверов, API и отправки данных. Три уровня агрессивности, мгновенная статистика и поддержка тёмной темы.
